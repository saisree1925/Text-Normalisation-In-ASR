# Text Normalization in ASR

This project performs text normalization for Automatic Speech Recognition (ASR).

## How to Run
1. Open terminal
2. Run: python app.py
3. Open browser and go to: http://127.0.0.1:5000
## Technologies Used
- Python
- Flask
- HTML
- VS Code
